# T Funk Era Case Files Coloring Book

## Project Goal
Create a **30-case black-line coloring book** based on creepy and mysterious Case Files as a new **income stream** under the T Funk Era brand.

The book should feel like a mysterious archive of unexplained cases rather than a generic coloring book. It combines eerie subject matter, concise case identification, clean printable line art, and a direct path to the full Case Files at **TFUNKERA.COM**.

> **Working document:** Creative choices below are intentionally editable. KDP technical requirements must be rechecked against Amazon's current specifications before final export/upload.

## Core Creative Decisions — Working
- **30 cases**
- **Black line art interior**
- Creepy / eerie cases encouraged
- Sellable Amazon KDP paperback and T Funk Era brand extension
- Each case identifies:
  - **Case File Number**
  - **Case Title**
  - **Short description: 2–3 sentences**
  - One black-and-white coloring illustration
- Illustrations should be the dominant element.
- Case information should feel like a case-file caption rather than a generic coloring-book caption.
- **Single-sided coloring artwork is preferred.** Working layout places coloring art on a right-hand page with the reverse left blank or minimally branded.
- Website integration is part of the product: readers can use the Case File number to find the full case, evidence, history, sources, and T Funk Take at TFUNKERA.COM.

# Amazon KDP Production Requirements

These are **technical constraints**, not creative preferences. Recheck KDP immediately before creating final production PDFs because Amazon may change specifications.

## Current Planned Print Configuration
- Format: **Paperback**
- Trim size: **8.5 x 11 in**
- Interior: **Black ink on white paper**
- Cover: **Full color**
- Finish: **Glossy — working choice**
- Expected final length: approximately **100 pages**, using 30 single-sided coloring pages plus activity pages, solutions, front matter, and back matter while keeping the coloring artwork single-sided
- KDP classifies 8.5 x 11 as a **large trim size**.

### Supported Page Count
Current KDP specification for **8.5 x 11, black ink, white paper**:
- Minimum: **24 pages**
- Maximum: **590 pages**

## Interior File
- KDP requires **single-page files**, not two-page spreads / 2-up layouts.
- Print-ready PDF is preferred for this image-heavy book.
- If any interior content uses bleed, the manuscript must be a fixed-format PDF and the **entire interior file must be set up for bleed**.
- Fonts must be embedded.
- KDP minimum interior font size: **7 pt**.
- Final interior must be checked in KDP Print Previewer before publishing.

## Interior Margins
For a book from **24–150 pages**, current KDP minimums are:
- Inside / gutter: **0.375 in**
- Outside margin, no bleed: **0.25 in minimum**
- Outside margin, with bleed: **0.375 in minimum**

### Project Safety Margin
Do not design important Case File numbers, titles, descriptions, faces, or critical illustration details directly against KDP's minimum margins. Use additional visual breathing room where practical.

## Interior Bleed
Bleed remains an **editable production decision**.

If we use no interior bleed:
- Page size = final trim size: **8.5 x 11 in**

If any illustration/background reaches the trimmed edge:
- Entire manuscript must be set up as bleed.
- KDP bleed extends **0.125 in** past the top, bottom, and outside edge.
- For an 8.5 x 11 trim, the bleed PDF page size would therefore be **8.625 x 11.25 in**.

Current preference: keep coloring illustrations safely inside the page rather than forcing full-bleed art unless the final design benefits from bleed.

## Cover Requirements
- Final cover is uploaded as **one continuous PDF** containing:
  - Back cover
  - Spine
  - Front cover
- **All KDP covers require bleed.**
- Cover images intended to reach the edge must extend **0.125 in** beyond trim.
- KDP recommends cover images at **300 DPI minimum**.
- KDP specifies CMYK for cover images for print consistency.
- Flatten cover artwork/layers for final production.
- Embed fonts.
- Keep important cover content safely away from trim/fold/spine areas.

### Spine
Do **not** finalize cover dimensions until the final interior page count is known.

For black ink / white paper, KDP currently calculates spine width as:

**page count × 0.002252 in**

KDP requires at least **79 pages** for spine text. If the final manuscript remains below 79 pages:
- **NO SPINE TEXT**

Use the official KDP Cover Calculator / template generator after the final page count, trim size, ink, and paper are locked.

## Barcode
- KDP can automatically place a barcode on the back cover if we do not supply our own.
- Therefore, back-cover design must reserve a safe barcode area and avoid placing the QR code, URL, important text, or important artwork where KDP may place its barcode.
- Final back-cover layout should be built using the KDP cover template generated for the actual final page count.

## Printing Cost — Planning Reference Only
Current Amazon.com black-ink paperback pricing for **large trim, 24–110 pages** is a fixed **$2.84 per book**. There is currently no per-page charge within that range.
- Printing is on demand.
- No inventory is required.
- Bleed setting and glossy vs. matte cover finish do not change the printing cost.
- **This price can change and must be rechecked before launch.**

## Proof Requirement — Project Rule
Before publishing:
1. Upload final interior and cover.
2. Run KDP Print Previewer and resolve all warnings/errors.
3. Order at least **one physical proof copy**.
4. Check:
   - line weight / print darkness
   - illustration detail
   - gutter comfort
   - text size/readability
   - page order and blank reverse pages
   - trimming
   - cover color/contrast
   - front-cover thumbnail readability
   - back-cover barcode clearance
   - QR code scan reliability
   - TFUNKERA.COM spelling and destination
5. Make corrections if needed.
6. Only then approve the production version.
