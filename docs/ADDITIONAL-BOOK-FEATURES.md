# Additional Book Features — Planned Front & Back Matter

These features are approved for inclusion in the Case Files coloring book concept. Exact wording, typography, page order, and final layout remain editable until the book interior is finalized for Amazon KDP.

The goal is to make the book feel like an interactive Case Files dossier rather than simply a collection of coloring pages, while keeping the experience easy to use and inexpensive to print.

## 1. This Book Belongs To / Investigator Record

Place near the beginning of the book.

Working concept:

**T FUNK ERA — CASE FILES**  
**FIELD INVESTIGATOR RECORD**

Name: ____________________________________

Date: _____________________________________

Optional additional field if space/design allows:

Investigator ID / Codename: ______________________________

Possible small footer treatment:

**Property of the T Funk Era Case Files Division**

Exact wording and whether the optional codename field is retained can be finalized during interior layout.

## 2. How to Use This Book

Include a brief introductory page explaining that each coloring page is based on a real mystery, legend, unusual historical event, cryptid report, UFO case, or other published T Funk Era Case File.

The page should explain that:

- Each illustration includes its real T Funk Era Case File number and identifying information.
- The short caption gives enough context to understand what is being colored.
- Readers can visit TFUNKERA.COM or use the book's QR code to explore the complete Case File, evidence, history, and sources.
- The book is intended to be colored, explored, and used as a starting point for further investigation.

Keep this page concise and visually consistent with the dossier/case-file theme.

## 3. Case File Checklist / Index

Include a checklist or index listing all 30 cases in the book.

Working format:

- [ ] CF-#### — Case Title
- [ ] CF-#### — Case Title
- [ ] CF-#### — Case Title

Continue through all 30 cases using the actual T Funk Era Case File numbers rather than sequential coloring-book page numbers.

Purpose:

- Gives readers an overview of the book.
- Lets readers check off completed pages.
- Reinforces the collectible Case Files concept.
- Makes individual subjects easier to locate.

Final placement can be near the beginning or end depending on pagination and print layout.

## 4. Investigator Notes

Include an **INVESTIGATOR NOTES** area as an interactive feature.

This should provide blank ruled space where readers can record thoughts, theories, observations, favorite details, or questions about the cases.

Possible implementation options:

1. One or more dedicated Investigator Notes pages in the back matter.
2. A small notes area associated with selected Case Files if page space permits.

Do not reduce the main coloring area significantly just to add notes. Dedicated notes pages are preferred if the individual case-page layout becomes crowded.

## 5. Test Your Colors Page

Include a page near the front where readers can test crayons, colored pencils, markers, gel pens, or other coloring tools before using them on a finished Case File page.

The page should contain simple black-line test shapes and small areas with different line densities rather than decorative art that competes with the main Case Files.

Suggested label:

**TEST YOUR COLORS**

Optional small note reminding readers that some markers may bleed through paper and should be tested first.

The final design should remain black line art on white and match the visual language of the rest of the book.

## 8. Website / QR Finale

Retain the existing website connection as a dedicated final/back-matter feature in addition to the back-cover treatment.

Approved working message:

**THE MYSTERY DOESN'T END ON THE PAGE.**

Explore the complete Case Files, evidence, history, sources and more at

**TFUNKERA.COM**

A QR code should point to the T Funk Era Case Files archive or another final verified destination.

The URL and QR destination must be tested before publication.

This feature should help move readers naturally from the physical coloring book to the complete online Case Files archive.

## Working Interior Flow

A possible book flow to test during layout:

1. Title / publishing page
2. This Book Belongs To / Field Investigator Record
3. How to Use This Book
4. Test Your Colors
5. Case File Checklist / Index
6. 30 Case File coloring pages
7. Investigator Notes
8. My Favorite Case
9. Certificate of Completion
10. Website / QR finale

This order is a working structure, not a locked pagination requirement. It may be adjusted to satisfy Amazon KDP page-count, printing, bleed, verso/recto, and interior-layout requirements.

## Production Note

These features should add personality and interactivity without overwhelming the 30 primary coloring pages. The Case File illustrations remain the main product. Front and back matter should support the central experience, strengthen T Funk Era branding, and create a clear connection to the website.
