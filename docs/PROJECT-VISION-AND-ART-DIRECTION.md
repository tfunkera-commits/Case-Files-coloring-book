# Case Files Coloring Book — Project Vision & Art Direction

## Project Goal

Create a 30-case T Funk Era coloring book for Amazon KDP using only Case Files that have already been published on T Funk Era.

The book should work on two levels:

1. Be an enjoyable, visually interesting coloring book.
2. Introduce readers to unusual subjects they may not already know and give them an easy path to learn more through the full T Funk Era Case Files.

The project is intended to become an additional T Funk Era income stream while also driving discovery of the website and Case Files archive.

## Core Reader Experience

A major inspiration is the experience of seeing unfamiliar characters in childhood coloring books. A reader should be able to encounter a strange creature, UFO, or mystery on the page even if they have never heard of it before.

Each page should therefore identify the subject clearly and provide enough context to make the reader curious about the larger story.

The coloring book should feel like opening a collection of illustrated case dossiers rather than a generic collection of monsters or UFO drawings.

## Primary Visual Reference

The strongest visual inspiration is vintage G.I. Joe-style coloring-book artwork.

Important: the aged/orange paper seen in some reference images is NOT part of the desired style. Final artwork should be clean black line art on a white background.

### Desired Illustration Style

- Clean black line art on pure white.
- Comic-book realism rather than childish/cartoon artwork.
- Dynamic poses and compositions.
- One large, recognizable subject should dominate each page.
- Strong outer contours around the primary subject.
- Clear interior details that remain practical to color.
- Environmental details should establish location and atmosphere without overwhelming the central subject.
- Open areas should remain available for coloring.
- Portrait-oriented compositions suitable for a printed coloring book.
- Generous print-safe margins.
- Consistent visual language across all 30 pages.

### Avoid

- Photorealistic pencil-sketch rendering.
- Excessive crosshatching.
- Heavy grayscale shading.
- Large areas filled solid black when those areas could instead be colored by the reader.
- Overly intricate adult-coloring-book patterns that distract from the Case File subject.
- Simplistic preschool-style cartoon art.
- Repetitive compositions.
- Aged paper, sepia, orange, or faux-vintage paper coloration in the production artwork.

## Page Structure

Each coloring page should function as a self-contained Case File introduction.

The illustration occupies the majority of the page.

A consistent information area near the bottom should be inspired by vintage character coloring-book captions while using an original T Funk Era layout.

The information area should include:

- Case File number.
- Subject/title.
- Location when useful.
- A short description, generally 2–3 sentences.
- Enough information for a reader unfamiliar with the subject to understand what they are coloring.
- Language that creates curiosity without overcrowding the page.

Example structure:

CASE FILE CF-0015

MOTHMAN — POINT PLEASANT, WEST VIRGINIA

Between 1966 and 1967, witnesses around Point Pleasant reported seeing a large winged humanoid with unusual glowing eyes. The sightings became one of America's most enduring cryptid mysteries.

Exact typography and layout will be finalized during sample-page development.

## Subject Selection

Only subjects already published as T Funk Era Case Files may appear in the initial 30-page book.

Selection priority:

1. Cryptids and creatures with visually distinctive characters.
2. UFO/alien cases with recognizable craft, beings, or encounter scenes.
3. A small number of visually exceptional strange-history or mystery cases for variety.

docs/30-CASE-LINEUP.md

## Composition Philosophy

Every page should have a clear focal point.

The central subject should be recognizable even when viewed as a small thumbnail.

Backgrounds should tell the reader where the event occurs and help communicate the story.

Examples:

- Mothman: winged figure as the dominant subject with Point Pleasant context.
- Mongolian Death Worm: creature erupting from the Gobi Desert.
- Rendlesham Forest: unusual craft among tall pine trees.

The 30 pages should vary in mood and composition. Some may feel creepy, others mysterious, majestic, adventurous, technological, or strange.

## Website Connection

The coloring book should intentionally connect readers back to T Funk Era.

The back cover should include the following concept:

THE MYSTERY DOESN'T END ON THE PAGE.

Explore the complete Case Files, evidence, history, sources and more at

TFUNKERA.COM

A QR code should be considered beside this message, pointing readers to the T Funk Era Case Files archive.

The purpose is to let someone who discovers an unfamiliar subject in the coloring book immediately continue exploring the complete Case File online.

The final URL/QR destination and back-cover layout should be verified before publication.

## Brand Relationship

The book is not intended to be a disconnected coloring-book product.

It should feel like a physical extension of T Funk Era's Case Files archive.

The relationship should be:

Coloring page -> curiosity -> Case File identification -> TFUNKERA.COM -> full story/evidence/sources.

## Production Workflow

1. Lock the 30 published Case Files.
2. Review coloring-book reference examples.
3. Lock this visual direction.
4. Develop a reusable page template and information-strip layout.
5. Produce three sample pages covering different visual challenges.
6. Review the samples for consistency, colorability, print suitability, and T Funk Era identity.
7. Revise and lock the production template.
8. Produce the remaining pages.
9. Write/finalize the 2–3 sentence Case File descriptions.
10. Build front matter, back matter, cover, website call-to-action, and QR treatment.
11. Perform print/KDP quality checks.
12. Prepare the final KDP-ready book.

## Locked Production Style — Approved Mothman Sample

The revised Mothman sample (CF-0015) is the approved visual baseline for the entire book. Future pages must match this level of simplicity, line weight, page structure, and colorability closely enough that all 30 pages feel drawn for the same book.

### Detail Density

- Target approximately 25% less detail than the first Mothman draft.
- Favor clean, deliberate contour lines over texture lines.
- Use interior detail only when it helps define anatomy, form, clothing, machinery, terrain, or a recognizable feature.
- Keep large white/open regions available for coloring.
- Wings, fur, foliage, water, stone, clouds, vehicles, buildings, and similar surfaces should be suggested with a limited number of lines rather than fully textured.
- Backgrounds should establish the real-world setting without competing with the main subject.
- Avoid dense hatching, repeated micro-lines, excessive cracks, tiny foliage, or other visual noise.

### Line Language

- Pure black line art on pure white; no gray wash, shading, gradients, sepia, or paper texture.
- Strong, smooth outer contour on the main subject.
- Moderately thinner interior/detail lines.
- Simple, readable shapes suitable for hand coloring.
- Comic-book realism: believable and dramatic, but not photorealistic and not childish.
- Keep line density visually consistent from page to page.

### Composition Baseline

- Portrait page with a thin rectangular border and generous print-safe margins.
- Illustration occupies roughly the upper 85–90% of the usable page.
- One dominant subject with a dynamic, immediately readable silhouette.
- Supporting environment remains secondary and simplified.
- Bottom information strip should be shallow and span the page width rather than consuming a large block of the illustration.
- Do NOT place the website promotion / “THE MYSTERY DOESN'T END ON THE PAGE” panel on individual coloring pages. That call-to-action belongs on the book's back cover/back matter.

### Information Strip Baseline

Use the approved Mothman layout as the template:

CASE FILE CF-#### | SUBJECT — LOCATION

Follow with a concise 2–3 sentence description in smaller readable type. The caption should identify what the reader is coloring and create curiosity without becoming a large text feature.

Case File numbers must use the actual T Funk Era Case File number from the production lineup/site. Do not renumber pages sequentially for the coloring book.

### Anti-Drift Checklist

Before approving each new page, compare it mentally against the approved Mothman sample and verify:

1. Similar overall line weight.
2. Similar amount of open white coloring space.
3. Similar detail density — do not gradually become more intricate.
4. Similar comic-book realism.
5. Main subject dominates the composition.
6. Background communicates setting but stays secondary.
7. No grayscale/shading/crosshatching creep.
8. Bottom strip remains compact and consistent.
9. Correct CF number, title, location, and concise description.
10. Page remains easy and enjoyable to color when printed.

If a subject naturally requires more technical detail (for example a UFO or aircraft), simplify secondary components rather than increasing the overall page density. If a subject is visually simple, add setting/context rather than decorative patterns. This keeps the perceived complexity consistent across the book.

### Generation/Revision Rule

Treat the approved revised Mothman page as the visual anchor for every future generation. New pages should change the subject, setting, pose, and case-specific storytelling while preserving the same production grammar: bold clean contours, restrained interior lines, simplified environment, generous white space, portrait framing, and compact case-file strip.
